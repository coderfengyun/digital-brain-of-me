# Agents Over Bubbles

**类型**: 叙事

---

## 📖 完整叙事

### 背景

2026 年 3 月，Nvidia GTC 前夕，AI 行业面临两个对立的质疑声：一是末日论（AI 太危险），二是泡沫论（所有投资都是浪费）。Ben Thompson 此前一直认为"泡沫也有好处"，但此时他改变了立场——他认为 AI 不是泡沫。

### 核心故事

Thompson 用**三个 LLM 范式跃迁**构建了他的论证主线：

**范式一：ChatGPT（2022.11）**
↓
让世界看到 LLM 的能力，但有两个根本缺陷：① 经常犯错 + 幻觉；② 需要用户主动引导和验证。
↓
**范式二：o1 推理模型（2024.9）**
↓
模型内部自我评估、反复推敲答案，大幅减轻用户"纠错"负担。ChatGPT 让 LLM "可用"，o1 让 LLM "可靠"。
↓
**范式三：Agents — Opus 4.5 + Claude Code（2025.12）**
↓
关键洞察：Opus 4.5 本身发布时反响平平，是 Claude Code **harness 的改进**让它突然变得强大。Agent = 模型 + harness + 工具，能自主验证结果、反复尝试，不需要人类参与。

每个范式都修补了前一个范式的缺陷，并指数级增加了算力需求。

### 关键转折

**转折一：Agency 的需求在减少而非增加**

用 agent 的人远少于用 chatbot 的人，但这不重要——一个有 agency 的人可以同时控制多个 agent。不需要大规模人类采用，少量高 agency 的人就能产生巨大的经济影响和算力需求。

**转折二：企业经济的必然性**

- 消费者只想消费内容，企业才愿意为生产力付费
- Anthropic 聚焦企业市场是正确的
- 大公司中真正推动进步的是少数人，但他们的影响力被庞大的组织协调成本稀释了
- Agent 将把"协调成本中的人类执行者"替换为不知疲倦的 agent，让少数关键人物的影响力倍增
- 企业会主动裁员 + 用 agent 重建规模，因为 AI 原生的小竞争者会从成本和能力两个维度施压

**转折三：Agent 颠覆了"模型商品化"的叙事**

- Dediu 认为 Apple 最聪明：不自建模型，授权 Gemini，拥有客户即拥有一切
- Thompson 反驳：推理模型已让本地推理不可行；更关键的是，agent 的差异化在于**模型与 harness 的集成**，而非单独的模型
- 利润流向集成的环节，远离模块化/商品化的环节（Apple 自身就是这个定律的典范）
- **例子：Microsoft 的 U 型转弯** —— 从"模型无关"的 Core AI 策略，到 Copilot Cowork 绑定 Anthropic 的模型，等于承认 agent 产品无法模型无关
- 这意味着 Anthropic 和 OpenAI 正成为 AI 价值链中的集成点，利润将流向它们

### 结果与意义

Thompson 的结论：三个因素叠加，AI 投资不是泡沫：
1. LLM 的弱点正被指数级增长的算力解决
2. 需要有效使用 AI 的人数在减少（但算力需求在增加）
3. Agent 的经济回报不仅影响利润底线，还影响营收上线

他的自我解嘲收尾：如果"宣布不是泡沫"本身是泡沫的最佳证据，那就这样吧。

---

## 🔑 关键洞察

- **Agent 的差异化不在模型，在 harness**：Opus 4.5 发布时平平无奇，Claude Code harness 的改进才是转折点。这意味着 AI 公司的护城河在于模型-harness 的集成，而非单一模型性能。

- **Agency 悖论：需要的人少了，影响反而大了**：Agent 把人从直接管理模型中抽象出来，一个人可以控制多个 agent。不需要大规模采用就能产生巨大算力需求和经济影响 —— 这是反直觉的"不是泡沫"论据。

- **利润流向集成，远离模块化**：这是 Thompson 的经典分析框架（来自 Clayton Christensen）。当 agent 需要 model + harness 的紧密集成时，模型不再是商品，Anthropic/OpenAI 成为价值链集成点。Microsoft 从"模型无关"到绑定 Anthropic 的 Copilot Cowork，是这一趋势的最佳证据。

- **企业裁员的逻辑不是"省钱"而是"重构规模方式"**：Thompson 区分了 eliminating jobs（消除岗位）和 replacing（替换），认为 agent 的真正价值是替换组织中的协调成本，让少数关键人物的 agency 乘以 agent 的执行力。
