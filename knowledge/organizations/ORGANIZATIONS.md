# Organizations Knowledge

本目录存放组织管理、决策机制、协作方式、企业运营和生产力相关的长期知识材料。

## Structure

```text
knowledge/organizations/
├── ORGANIZATIONS.md
└── 主题/
    ├── source.md
    └── notes.md
```

## 归档规则

- 文章重点是组织管理、决策机制、公司协作时放这里
- 文章重点是 AI 机制、agent 工作流、AI 产品或 developer tools 时放 `knowledge/ai/`
- 元数据登记在 `sources/sources.jsonl`
- 长文使用 `paper-reading` skill 处理，`output` 指向本目录下的 `notes.md`

## Scope

- 组织设计、层级、协作机制
- 企业 AI 转型中偏组织变革的部分
- 决策机制、共识问题、管理生产力
- 公司运营方式、团队结构、责任分配
