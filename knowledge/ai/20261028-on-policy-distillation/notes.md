## 🗺️ 全局地图

### 一句话摘要

> 在策略蒸馏从学生自身采样轨迹，再让强教师逐 token 提供反向 KL 监督，从而同时获得 RL 的状态相关性与 SFT/蒸馏的稠密反馈；它尤其适合把已发现的行为策略便宜地压入小模型或在知识更新后恢复旧行为。

### 结构地图

```text
后训练的两难
├─ RL：学生自己的状态，但只有终局稀疏奖励
└─ SFT/离策略蒸馏：逐 token 稠密监督，但只覆盖教师状态
              ↓
在策略蒸馏
学生生成轨迹 → 教师在同一轨迹算 log-prob → 逐 token 反向 KL → 更新学生
              ↓
两类验证
├─ 推理：60% AIME 起点 → 约 7.7 万 prompts 到 70%
└─ 个性化：知识中训后 IF-eval 79% → 83%，内部 QA 36% → 41%
              ↓
机制解释
稠密监督让“学会已找到的策略”远便宜于“用 RL 搜到策略”
              ↓
适用边界
教师行为必须大体处于学生支持集；它不能替代知识注入或真正的策略探索
```

## 📖 核心叙事

文章最有价值的地方，是把几种容易混在一起的后训练手段拆成两个正交维度：

1. **数据从哪里来**：学生自己（on-policy）还是教师/历史数据（off-policy）。
2. **反馈有多密**：整条轨迹一个结果（sparse）还是每个 token 一个信号（dense）。

SFT 位于“离策略 + 稠密”，RL 位于“在策略 + 稀疏”，在策略蒸馏补上“在策略 + 稠密”这个象限。它不是让教师重写标准答案，而是让学生先暴露自己真正会犯的错，再让教师在这些状态上给概率判断。

实现上，它把教师模型当成不可学习的过程奖励器。学生轨迹上的逐 token 反向 KL 越高，说明该 token 越不像教师在这个上下文中的选择。SimpleBench 例子尤其直观：真正被惩罚的是让推理走错方向的早期 token，最终错误答案因已被错误前文决定，反而没有高惩罚。这比“答案错了，整条轨迹一起扣分”的 RL 信用分配精细得多。

但它并不是 RL 的替代品。文章后半段其实给出了更准确的分工：**RL 用昂贵的搜索发现语义策略，蒸馏用便宜的稠密信号传播最终策略。** 如果教师没有好策略，蒸馏不会创造它；如果学生对教师行为的概率为零，反向 KL 也难以凭空扩展支持集。因此一个更现实的训练栈是：先预训练/中训注入知识与基本支持，再用 RL 或其他搜索找到策略，最后用在策略蒸馏把策略压入目标模型。

持续学习的实验则展示第二种用途：中期训练负责学新知识，旧版本模型作为教师负责“唤回”被覆盖的行为。这个阶段交替结构比试图在一次 SFT 中精调数据混合比例更稳健，也与 Digital Brain 里“知识更新”和“行为协议保持”应分开治理的思路很接近。

## 🤔 批判性思考

| 问题 | 分析 |
|---|---|
| 核心假设及失效场景 | **假设 1**：教师的高概率行为确实是目标行为；若教师有系统性偏差，方法会高效复制偏差。**假设 2**：教师行为在学生支持集内；学生从不生成的知识、工具调用或格式，反向 KL 很难教会。**假设 3**：能稳定、低成本地取得教师逐 token log-prob；闭源 API 通常不给 logits/logprobs，应用范围受开放权重或专用训练平台限制。 |
| 关键局限 | 推理主实验集中于 Qwen3 与 AIME’24；SFT 200 万样本达到 70% 是外推而非实测；FLOPs 与 GPU 小时的换算高度依赖系统实现；internal QA 是未公开评测，外部无法复核；文章由 Tinker 提供方撰写，存在产品叙事动机。 |
| 实验充分性 | 还需验证：跨模型家族、跨任务和长程 agent 轨迹；教师弱于或风格不匹配时的退化；完整 top-k/logit 蒸馏与只查询采样 token log-prob 的差异；与过程奖励模型、DAgger、online DPO 的同预算对比；多轮“学知识→恢复行为”后是否真的不累积遗忘。 |

### 我的判断

这篇文章的强结论不是“蒸馏优于 RL”，而是：

> **一旦好策略已经存在，继续用稀疏结果奖励重新发现它通常很浪费；让教师在学生真实轨迹上给稠密分布反馈，是更直接的策略迁移方式。**

其最适合的场景是“教师已有、学生较强、需要低成本适配或恢复行为”。最不适合的场景是“学生尚无相关知识/动作支持、教师本身不可靠，或任务真正需要探索出教师也不会的新策略”。

对 agent 训练尤其值得关注：长轨迹的 exposure bias 和错误累积比短问答更严重，因此 on-policy 状态覆盖价值更大；但逐 token 模仿教师也可能压低探索多样性。较合理的未来组合是：环境奖励负责保留探索，教师 KL 负责过程级信用分配，而不是让其中一个完全取代另一个。
