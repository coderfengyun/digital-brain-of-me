# 用因果信念图设计 AI 老师

> 边想边写，还不成熟。灵感来源于 *Simulating Society Requires Simulating Thought* 这篇论文中的 GenMinds 框架。

## 需求

AI 1v1 课堂中，AI 老师需要完成一个闭环：**感知学生异常 → 判断问题根因 → 选择干预动作 → 验证干预效果**。

现状是 AI 纯文本分析准确率只有 60%，核心问题是"看不到本质"——AI 能看到学生做错了，但不知道他为什么错。

## 核心概念：因果信念图

**一句话描述：因果信念图是一个有向图，节点是学生关于某个知识主题的因果信念，边是信念之间的因果关系。**

来源于认知科学中的 causal belief graph 概念（GenMinds 框架中称为 cognitive motifs → causal belief graph 的构建流程）。在教育场景下的含义是：

```
学生脑中的因果信念图  vs  正确的因果信念图  →  diff 就是教学目标
```

举例：在"分数大小比较"这个主题下——

正确信念图（部分）：
```
分数值 ← 分子/分母的比值关系
分母 → 每份的大小（分母越大每份越小）
分子 → 份数（取了多少份）
```

某学生的错误信念：
```
分母 → 分数大小（分母越大分数越大）  ← 错误的因果边
```

教学目标 = 删掉这条错误边，建立正确的因果路径。

## 从教育本质看：新知课教的就是一个因果信念图

从教育本质或直播课本质来看，就是老师不断诊断学生的因果信念，看有没有错误的，纠正并改正，然后在下次练习里确认巩固。也就是说，新知课教的就是一个因果信念图。

## AI 老师的工作流：诊断 → 纠错 → 验证

### Step1：信念图裁剪——缩小搜索空间

对于每轮学生发言结束后，AI 老师不需要考虑整个主题的因果信念图，而是做一次裁剪：根据当前题目和学生的表现，判断他最有可能落在因果信念图的哪个子图范围内。

```
完整因果信念图（主题级）
      ↓ 裁剪（基于当前题目 + 学生表现）
相关子图（当前诊断范围）
```

### Step2：高置信度直接纠错 vs 低置信度启动诊断

这是设计中最关键的分流逻辑：

**高置信度场景——直接纠错：**
当因果信念图里有一些很显而易见的问题，会带来非常直接明确、可映射回去的结果时，AI 可以高置信度地判断出错误的因果信念，直接对其纠错。

```
学生行为 → 直接映射到信念图中的某条错误边 → 纠错
```

**低置信度场景——启动诊断访谈：**
如果学生的表现不足以判断他的错误因果信念在哪里，那么就要启动一个诊断。实际上就是根据学生的表现，结合因果信念图来决定一个半结构化的访谈，挖掘学生的错误因果概念。

```
学生行为 → 无法确定具体错误边 → 生成诊断问题 → 学生回答 → 定位错误 → 纠错
```

这和 GenMinds 框架中用半结构化访谈提取 cognitive motifs 的思路是一致的——AI 老师同样是在通过访谈提取学生的信念图，只不过目标不止于提取，更关键的是定位并更正信念图中错误的部分（节点或边）。

### Step2.5：基于错误类型选择教学手段

定位到错误的因果信念之后，不同种类的错误应该采用不同的教学手段来纠正。如果能建立"错误类型 → 教学手段"的映射，整个框架就比较完整了：

| 错误类型 | 示例 | 适配的教学手段 |
|---------|------|--------------|
| 错误的因果边（方向反了） | "分母越大分数越大" | 反例对比：给两个分母不同的分数让学生直观感受 |
| 缺失的因果边 | 不知道分母和"每份大小"的关系 | 概念引入：用切蛋糕等具象类比建立新的因果联系 |
| 多余的因果边（过度泛化） | "数字越大结果越大"不区分分子分母 | 边界测试：构造反直觉的练习暴露泛化的失效 |
| 节点概念错误 | 把"分数"理解为"两个独立的数" | 重新定义：回到概念源头重建理解 |

这一步的价值在于：AI 老师不只是"发现问题"，而是能根据问题的类型自动选择最合适的纠正策略，让干预更精准。

### Step3：验证——在练习中确认新的因果信念

纠错之后，需要形成明确的应对方案，再找更多练习，让学生把正确的因果信念建立起来。验证标准：学生在后续练习中不再触发同一错误路径。

## 优势分析

### 教学目标变得可计算
传统 AI 老师的目标是模糊的（"教会学生"），但因果信念图把教学目标转化成了一个明确的数据结构——学生信念图和正确信念图之间的 diff：
- 教学进度可量化（修正了多少错误节点/边）
- 教学效果可验证（下次练习是否不再触发同一错误路径）
- 不同学生可以有完全不同的教学路径，因为他们的 diff 不同

### 诊断和教学自然解耦
框架天然区分了两种场景：高置信度直接纠错 vs 低置信度启动诊断。这比"一刀切地解释"要高效得多——它让 AI 知道什么时候该教、什么时候该问。

### 与 LLM 能力高度匹配
LLM 天然擅长因果推理、从文本中提取信念、生成诊断性问题、根据上下文调整解释方式。因果信念图给了 LLM 一个结构化的思考框架，而不是让它在开放空间里漫无目的地"当老师"。

## 挑战与风险

### 因果信念图的构建是最大瓶颈
每个知识点/主题都需要领域专家构建（或至少审核）。图的粒度很难把握——太粗会漏掉关键错误信念，太细会爆炸。不同学科差异极大：数学的因果信念图相对清晰，语文/英语的就很模糊。

### 学生的错误信念可能不在图里
真实学生的错误信念可能是专家完全预料不到的。比如"分数线越长值越大"——这种错误信念可能根本不在预设的图中。系统需要有能力处理图外的异常，否则会在最需要诊断的时候失效。

### 从行为到信念的推断是一对多的
同一个错误答案可能源于完全不同的错误信念。半结构化访谈可以缓解，但会显著拉长交互轮次，在实时课堂场景下时延成本很高。

### 纯认知模型，缺失情感维度
因果信念图是纯认知层面的模型。但真实教学中，学生不学可能不是"信念错了"，而是"不想学"、"焦虑"、"分心"。需要与情绪/专注度信号做互补。

## 待验证的实验

**"AI 老师不考虑时延"实验：**
在不受实时交互时延约束的离线环境下，让 AI 老师充分使用因果信念图做诊断和纠错，看它能达到多好的教学效果。这个实验的价值在于：先测出框架的能力上限，再考虑如何在实时约束下做取舍。

## 扩展思考：因果信念图用来做模拟学生可能更靠谱

上面讨论的是用因果信念图驱动 AI 老师，挑战不小。但换一个方向想——用因果信念图来构建**模拟学生**（Simulated Student），可能是更现实、更先落地的路径。

### 为什么模拟学生比 AI 老师更适合这个框架

核心区别在于：AI 老师需要做**开放式推理**（诊断、决策、生成教学动作），而模拟学生只需要做**受约束的行为生成**（给定信念图，输出符合该信念的行为）。

| 维度 | AI 老师 | 模拟学生 |
|------|---------|---------|
| 任务性质 | 开放式：诊断 + 决策 + 生成 | 受约束：基于给定信念图生成行为 |
| 信念图的角色 | 需要实时提取和推断（难） | 预先设定，作为输入（易） |
| 容错要求 | 高——误判会伤害教学效果 | 低——不完美的模拟学生也有训练价值 |
| 图外异常 | 必须处理（真实学生不可预测） | 不需要（模拟学生的信念就是图本身） |
| 实时性约束 | 强（课中决策） | 弱（离线模拟为主） |

### 模拟学生的构建方式

给 LLM 一个带有特定错误的因果信念图作为 persona，让它按照这个信念图来"当学生"：

```
输入：
- 正确的因果信念图
- 需要注入的错误（如：删掉某条边、反转某条边、加一条错误边）
- 当前题目

输出：
- 该"学生"在此错误信念下的自然行为（回答、提问、沉默、困惑表现）
```

### 模拟学生的价值

**1. AI 老师的训练场**
在真实学生上线之前，用模拟学生来测试和训练 AI 老师的诊断能力。可以系统性地遍历各种错误信念组合，验证 AI 老师能否正确识别和纠正。

**2. 课程设计的压力测试**
新课程上线前，用各种"错误信念配置"的模拟学生跑一遍，看课程设计能否覆盖常见的错误路径。相当于教学设计的单元测试。

**3. badcase 复现和回归**
把真实课堂中遇到的 badcase 转化为模拟学生的信念图配置，形成可复现的测试用例。修改了 AI 老师的策略后，用这些模拟学生做回归测试。

**4. 教研培训工具**
让人类老师和模拟学生互动，训练老师识别和处理各种错误信念的能力。比现有的案例学习更接近真实体验。

### 为什么这条路更可行

回到之前提到的挑战——因果信念图的构建成本、图外异常、行为到信念的一对多映射——这些对 AI 老师来说是硬伤，但对模拟学生来说要么不存在要么大幅降低：

- **构建成本**：模拟学生不需要穷举所有可能的错误信念，只需要覆盖高频的、有代表性的错误即可
- **图外异常**：不存在，模拟学生的信念就是你给它的信念图
- **一对多映射**：方向反了——模拟学生是从信念到行为（一对一），而不是从行为到信念（一对多）

一句话：**模拟学生是因果信念图的"顺流"应用（信念→行为），AI 老师是"逆流"应用（行为→信念）。顺流天然比逆流简单。**

## 下一步

1. 选一个小领域（如某个数学单元）手工构建因果信念图，评估构建成本
2. **先做模拟学生**：用因果信念图 + LLM 构建几个典型错误信念的模拟学生，验证行为输出的合理性
3. 用寒假课 badcase 数据做回测——看因果信念图能否解释现有的未完课案例，同时把 badcase 转化为模拟学生配置
4. 用模拟学生测试现有 AI 老师的诊断能力，找到改进方向
5. 设计"不考虑时延"的离线实验，验证 AI 老师框架的上限
