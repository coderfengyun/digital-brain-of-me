# 修行&内观

### 工作

* **从题型覆盖走向作业与讲法生成**
  * 当大部分题型已经覆盖后，可以直接为学生讲作业，以此映射学生对各类题型的掌握情况。
  * 对作业结果进行归因，提取学生已有经验与错误模式；结合历史题目中的正确解析，自动生成该题的讲法。
* **训练与评测框架**
  * 当前火热的反编译、逆向工具，可以从信息量与方法论的角度重新解释。过去的问题在于变量名和方法名被混淆；对 AI 而言，核心不是恢复原名，而是依据方法论重新获得解决方法。
  * Coding Agent 训练中 Reject Sampling 时的检查，可以映射到 AI Tutor 的 Rubrics：最终结果、中间状态、工具权限、行为轨迹、Verifier 是否被篡改，以及是否满足独立的安全约束。
  * 可以把 SET 与 RL 放进同一视角：Mask 掉 SET 时的部分轮次，相当于这些轮次奖励为 0；未 Mask 的轮次则提供正向奖励。
* **板书生成系统的架构分工**
  * 由 System Prompt 统一估计板书容量，并判断需要删除或压缩哪些内容。
  * 将布局模块做成智能 Executor，由它决定最终板书或组件的放置位置。
  * 场控可以从讲解模型获得更丰富的上下文，从而形成更大范围、更准确的判断。
* **从单次任务扩展到长期自适应学习规划**
  * 系统需要额外判断当前任务是否可以结束，或是否需要调整对学生学习目标的预期。短期看合理的选择，可能要放到长期学习任务中完成。
  * 任务顺序本身代表系统预期；当学生状态超出预期时，调整可能影响的不只是当前任务，而是整个学期的规划。
  * 主顺序应遵循认知金字塔：实际理解与应用、进阶应用、综合应用；辅助能力则作为第二优先级小目标，在需要时逐步强化。

这些想法共同指向同一件事：AI 教学系统不能只负责单轮生成，还需要具备评估、规划、执行、验证和跨时间尺度调整的完整闭环。
