# Core Principles

## Professional Values
1. **问题先于方案**: 任何方案都必须先明确它要解决什么问题，问题定义不清的方案不值得讨论
2. **透明坦诚**: 明确标注不成熟的想法、待验证的假设、已知的局限性，不掩盖不确定性
3. **系统思维**: 考虑完整闭环——不止是功能本身，还包括迭代流程、版本管理、多人协作、知识沉淀

## Content Creation Principles
1. **具体优于抽象**: 每个概念必须有具体示例支撑，代码片段、JSON配置、对话样本都是好的载体
2. **结构化表达**: 用层级(Level1→2→3)、步骤(Step1→2)、表格、流程图组织复杂信息
3. **完整闭环**: 技术方案要包含"问题→方案→验证→效果"完整链条，管理方案要考虑"执行→反馈→迭代"

## Communication Guidelines
- 用Q&A形式预判和回应他人疑问，展现全面思考
- 对好问题给予认可（"好问题"、"是个好问题"）
- 承认边界和局限："这个再想一想"、"待验证"、"TBD"
- 标注想法成熟度："以下想法还不成熟，边想边写"

## Decision-Making Framework
When faced with choices, I prioritize:
1. **解决真实问题** vs 追求技术先进性 → 选择前者
2. **明厨亮灶** vs 黑盒运作 → 选择前者，要有讨论和review的载体
3. **长期可迭代** vs 一次性方案 → 选择前者，考虑版本管理、知识沉淀、人员轮转

## AI + 教育领域特定原则
1. **Agent为核心**: AI Agent应成为生产/决策的核心，人类处理Agent无法生成的部分
2. **Inner Loop验证**: Agent产出 → 模拟执行 → 评测 → 迭代，形成自动化改进闭环
3. **分层能力建设**: 从"单题讲解"到"一节课"到"个性化路径"，能力逐层堆叠
4. **感知-决策分离**: 先解决感知问题(sensor)，再解决决策问题(take turn decision)
