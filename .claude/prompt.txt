<教学任务>
# 环节教学任务
探究发现封闭图形植树中棵数等于间隔数的规律。

# 任务详情


1. 引入：从围成一圈的种树场景引出封闭图形植树的研究问题
   1.1 观察图书馆周围围成一圈的植树场景
      - 教学动作：用话术1把学生从上节课的直线植树带进图书馆围一圈种树的场景，再展示周围种了一圈树的图片，请学生观察这批树与马路边一排树的排列差异——看学生能否抓住"沿图书馆围成一圈、首尾相接"的排列特点。
      - 常见问题1：学生只回应"树很多"，没有抓住"围成一圈"的排列特点
        - 问题1解释：引导沿图书馆围墙走一圈找树，指出树首尾相接围成一圈，点出与直线排树的差异后回到默认推进点。
      - 路径调整1（学生直接说出树是围成一圈、首尾相连，且和直线植树不同）：快速确认观察结论，跳过引导发现的过程，直接进入1.2引出本课研究问题。

   1.2 引出"封闭图形中棵数和间隔数是什么关系"
      - 教学动作：出示图书馆周围种树的题目，让学生读入题面；随后用话术2制造"看两端失效"的认知冲突，抛出"还能不能像直线型那样直接看两端"的问题——看学生能否意识到封闭图形没有分开的两个端点，从而建立"没有端点时棵数和间隔数是什么关系"的研究问题。
      - 关键提问：这次种树和直线上的植树不一样了，还能像直线型的植树问题一样，直接看"两端"吗？（提问意图：诊断学生是否意识到封闭图形没有分开的两个端点，从而建立本节课要研究的新问题：没有端点时，棵数和间隔数是什么关系。）
      - 常见问题1：学生仍认为能按直线型"看两端"，或说不出围成一圈意味着什么
        - 问题1解释：回到围成一圈的图片，引导学生看出树首尾相连、没有两个分开的端点，把问题收束成"没有端点时棵数和间隔数是什么关系"。
      - 常见问题2：学生想不起上一节直线型怎样由两端定棵数
        - 问题2解释：简要带学生回顾直线型中先算间隔数、再由两端栽不栽定棵数，再点出封闭场景没有分开的端点，正是本课要研究的新情况。

2. 圆形封闭图形规律建立：发现并理解棵数等于间隔数
   2.1 数圆上的一圈，发现棵数等于间隔数
      - 教学动作：借圆形教具展示周长上等距种树的画面，请学生从起点标记出发按顺序数一圈——看学生能否数出间隔数和棵数，并自己发现两者相等。
      - 关键提问：从起点标记开始数一圈，几个间隔？几棵树？（提问意图：让学生在教具上带标号逐个数出棵数等于间隔数的事实。）
      - 常见问题1：学生受直线两端都栽的影响，数完或算出后写成6+1=7棵
        - 问题1解释：先用话术3让学生回想"加1"的适用情形，再对照教具带学生重新数一圈，看到终点回到起点那棵、已被数过不能重复算，确认圆上就是棵数等于间隔数，再进入2.2。
      - 常见问题2：学生数间隔的顺序混乱，出现漏数或重复数
        - 问题2解释：引导从起点标记出发按顺序一段段数，让每棵树对应一个间隔，数正确后再确认棵数等于间隔数。
      - 路径调整1（学生数得快且直接说出棵数等于间隔数）：压缩逐个数数的引导，用教具快速确认事实后，直接进入2.2深挖"为什么相等"。

   2.2 展开圆解释棵数等于间隔数的原因，并提炼封闭图形判断标准
      - 教学动作：用话术4承接数数结论、过渡到"为什么相等"的探究，把圆形教具剪开展成一条线段，请学生观察展开后左端与右端的树，追问"右端接回哪里"——看学生能否看出右端不是新的端点树、而是接回开头那棵树，从而理解每个间隔正好对应一棵树；随后用话术6把圆的经验收束成"顺着边走一圈能回到起点、没有分开的两个端点就是封闭图形"的判断标准。
      - 关键提问：展开后，右端接回哪里？（提问意图：让学生从展开后的视觉形态看出右端并不是新的端点树，而是接回起点那棵树，因此终点树不能重复计算。）
      - 常见问题1：学生看到展开后的线段说不出是哪种情况
        - 问题1解释：用话术5引导学生逐端观察展开后的线段——左端有没有树、右端呢，认出右端没有多出一棵新树、接回去就是左端开头那棵树，从而理解每个间隔正好对应一棵树，回到棵数等于间隔数的推进点。
      - 常见问题2：学生对"封闭图形"这一名词陌生，不明白判断标准的意义
        - 问题2解释：回到未展开的圆，沿圆周走一圈演示回到起点、没有分开的端点，建立名词与图式的联系后再收束判断标准。
      - 路径调整1（学生看图即说出右端接回开头那棵树，并自己推出棵数等于间隔数）：压缩右端追问，直接确认规律并提炼封闭图形判断标准，带领完成板书记录。

3. 拓展到其他封闭图形：规律不依赖形状，只取决于首尾相连
   3.1 判断长方形也是封闭图形，迁移棵数等于间隔数
      - 教学动作：用话术7过渡到"换一种封闭图形规律是否还成立"的探究，出示长方形操场种树题目，让学生读入题面；随后用刚提炼的封闭图形判断标准发问——沿操场边走一圈能否回到起点——看学生能否识别长方形也是首尾相连的封闭图形；确认后迁移"棵数等于间隔数"，把周长计算只作为求具体棵数的后置应用。
      - 讲解重心：本步的核心认知推进是让学生用"顺着边走一圈能回到起点、没有分开的两个端点"的标准，先识别长方形也是封闭图形、棵数仍等于间隔数，让规律摆脱对圆形形状的依赖；周长计算放在确认规律之后，作为求具体棵数的后置应用。存在认知陷阱：学生可能跳过结构是否首尾相连的判断，一上来就只算周长。
      - 关键提问：长方形操场沿着边走一圈，最后会不会回到起点？所以它也是什么图形？（提问意图：引导学生用圆形阶段刚提炼出的"顺着边走一圈能回到起点、没有分开的两个端点就是封闭图形"的判断标准，识别长方形也是封闭图形，避免一开始就把注意力放到周长计算上。）
      - 常见问题1：学生算周长时只算长加宽、漏乘2，得到100
        - 问题1解释：用话术8引导学生数一数走完一圈长边会遇到几次，自己想出长方形有4条边、长宽各2次，周长是长宽和的2倍，再继续算间隔数得棵数。
      - 常见问题2：学生不认可长方形能沿用圆的规律，认为形状不同规律可能不同
        - 问题2解释：带学生沿操场边画一圈，确认与圆一样首尾相接、没有分开的端点，棵数仍等于间隔数。
      - 路径调整1（学生直接判断长方形是封闭图形、并已动手算周长和棵数）：跳过封闭判断的反复确认，直接核对周长、间隔数、棵数的计算路径，用教具验证后进入3.2。

   3.2 展开长方形，验证形状变化不影响棵数等于间隔数
      - 教学动作：把长方形教具展开成一条线段，让学生对照展开后的形态确认右端同样接回起点、没有多一棵树；再折叠回长方形，看学生能否理解形状改变但首尾相接的结构不变，棵数仍等于间隔数。
      - 常见问题1：学生用分边算验证时，每边的棵数算不准或合并时算错
        - 问题1解释：借展开后的线段说明每边按"一端栽一端不栽"逐边求棵数再相加，结果与整体算法一致。
      - 路径调整1（学生看到展开图直接说出结构和圆一样、棵数相同）：压缩展开讲解与分边算验证，直接进入3.3推广到其他封闭图形。
      - 路径调整2（学生在3.1之后仍不理解展开后为什么还是一端栽一端不栽）：回溯2.2圆的展开演示，对比两个展开图两端接回的关系后，再回到3.2继续验证。

   3.3 推广到不规则轮廓的封闭图形
      - 教学动作：出示小猫、Labubu等不规则轮廓的种树图，请学生逐一判断沿轮廓走一圈能否回到起点——看学生能否把判断标准迁移到不规则图形，理解封闭取决于首尾相连、而非形状是否规则；最后用话术9升华"形状不影响规律、关键是首尾相连"的结论。
      - 常见问题1：学生认为只有圆、长方形这类规则图形才算封闭图形
        - 问题1解释：沿不规则轮廓走一圈演示回到起点，确认封闭与否只看能否走一圈回到起点、首尾相连。
      - 路径调整1（学生直接说出不规则轮廓只要首尾相连就是封闭图形）：压缩逐轮廓判断，快速确认后直接进入4.1封闭与直线的对比总结。

4. 回顾总结：收束封闭图形的判断方法与做题提醒
   4.1 对比封闭图形和直线图形的结构差异
      - 教学动作：把直线型与封闭型种树并排对比，抛出"封闭型还有没有两个分开的端点"的问题，看学生能否从结构上说出封闭型没有端点、终点接回起点，因此不必像直线型那样看两端栽不栽。
      - 关键提问：直线型要看"两端栽不栽"，那封闭型还有两个分开的端点让我们看吗？（提问意图：通过"有没有两个分开的端点"这个判别点，引导学生对比直线型和封闭型的结构差异，避免让学生直接凭空概括"最大区别"。）
      - 常见问题1：学生能说出封闭型"不一样"，但说不清到底哪里不一样
        - 问题1解释：分别指直线两端和封闭图形的一圈，指出封闭图形走一圈回到起点、没有两个分开的端点，所以棵数不必加减1。
      - 路径调整1（学生直接完整说出封闭图形没有端点、终点接回起点、不用看两端）：压缩对比引导，直接进入4.2收束判断方法。

   4.2 收束封闭图形的判断顺序
      - 教学动作：与学生一起把判断顺序收束成"先判断是否封闭——沿边走一圈能否回到起点、有没有分开的端点，再据此定棵数等于间隔数"，用话术10带领学生把直线型与封闭型的对比及今天的方法一并收束，配合板书沉淀"先算间隔数、再看情况定棵数"的核心判断顺序。
      - 常见问题1：学生把判断顺序说反或漏掉"先判断是否封闭"一步
        - 问题1解释：用板书强调判断链路的稳定顺序——先看封闭与否，再定棵数关系，回到收束后的方法继续。
      - 路径调整1（学生能自己按顺序总结出封闭图形的判断方法）：请学生先完整总结，老师用板书确认补充，压缩老师逐步归纳的过程。

   4.3 明确没给总长时要先算周长
      - 教学动作：补充做题的数量意识提醒：题目没有直接给一圈总长时，要先求周长——周长就是封闭图形的一圈总长，再算间隔数得棵数。
      - 常见问题1：学生做题时忽略"没直接给总长要先算周长"，直接用已知量算棵数
        - 问题1解释：用长方形操场一题回顾"一圈总长就是周长，先算周长再算间隔数"，强化做题顺序。
