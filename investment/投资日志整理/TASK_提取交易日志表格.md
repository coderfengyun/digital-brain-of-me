# 核心任务
将 @ 杂活/投资日志整理/Private & Shared/周记&月结/ 文件夹中的每篇周记中包含的金融交易提取出来。
所有的投资交易都在 "# 投资"这个一级标题下。
把所有的金融交易提取成一个表格，输出为 `交易日志汇总表.csv`，**必须严格遵循下方的 CSV Schema**。
仅提取现货交易，合约交易不纳入此表。

# 输出 CSV Schema

Schema 的机器可读定义见 [交易日志汇总表.schema.json](交易日志汇总表.schema.json)（遵循 [Frictionless Table Schema](https://specs.frictionlessdata.io/table-schema/) 规范）。

以下为可读摘要：

## 列定义

```csv
序号,品种,操作类型,价格,数量,金额,币种,日期,日期精确度,备注
```

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| 序号 | string | required, unique, `^\d+$` | 唯一递增标识，纯数字（"1", "2", ...） |
| 品种 | string | required | 资产名称，需全局统一命名（同一资产在不同周记中必须使用完全相同的名称） |
| 操作类型 | string | required, enum: `买入` / `卖出` | 交易方向 |
| 价格 | number | required, ≥0 | 纯数值，每单位资产的价格（如黄金为 CNY/g，股票/ETF 为对应币种/股） |
| 数量 | number | required, ≥0 | 纯数值，交易数量 |
| 金额 | number | required, ≥0 | 纯数值，= 价格 × 数量（允许四舍五入误差 ≤1%） |
| 币种 | string | required, enum: `CNY` / `USD` / `HKD` | 交易结算币种 |
| 日期 | date | required, `YYYY-MM-DD` | 交易日期；若原始日期为周期范围，取范围起始日 |
| 日期精确度 | string | required, enum: `精确` / `周期范围` | 标记原始日期是精确日期还是周期范围 |
| 备注 | string | optional | 标注数据来源说明 |

## 数据约束

- 价格、数量、金额字段中**不得包含**货币符号（￥/$）、单位后缀（g/个/股）、≈ 前缀、任何非数字文字
- 若原文中数量为近似值（如 ≈65 股），应按 金额 ÷ 价格 计算精确值并填入，备注标注"数量由金额÷价格推算"
- 黄金价格统一为 CNY/g；若原文仅有国际金价（$/oz），需换算为 CNY/g 并在备注标注"价格由国际金价换算"
- 合约交易（开仓/平仓/多单/空单）不纳入此表

## 示例行

```csv
1,黄金,买入,791.48,2,1582.96,CNY,2025-05-06,精确,
2,白银ETF (SLV),买入,34.21,14.6,499.47,USD,2025-07-20,周期范围,
3,白银ETF (SLV),买入,76.51,65.35,5000.12,USD,2026-01-12,精确,数量由金额÷价格推算
```
