本目录存放两类数据：

1. **交易日志** — 统一的现货交易记录（`投资日志整理/`）

交易操作和投研管理流程由 `investment` skill 驱动。

## Data Schema

交易日志使用 CSV 格式，Schema 定义见 [`交易日志汇总表.schema.json`](投资日志整理/交易日志汇总表.schema.json)。

```csv
序号,品种,操作类型,价格,数量,金额,币种,日期,日期精确度,交易平台,备注
```

| 字段 | 类型 | 说明 |
|------|------|------|
| 序号 | string | 唯一递增标识 |
| 品种 | string | 资产名称（全局统一命名） |
| 操作类型 | enum | `买入` / `卖出` |
| 价格 | number | 纯数值，无货币符号 |
| 数量 | number | 纯数值，无单位后缀 |
| 金额 | number | = 价格 × 数量（误差 ≤1%） |
| 币种 | enum | `CNY` / `USD` / `HKD` |
| 日期 | date | `YYYY-MM-DD` |
| 日期精确度 | enum | `精确` / `周期范围` |
| 交易平台 | enum | `币安` / `富途` / `招行` / `招商证券` / `其他` |
| 备注 | string | 可选 |

## 投研文章归档规则

投资、宏观、地缘、能源、货币、资产配置、研报等文章默认按作者/机构归档：

```text
investment/{作者或机构}/{文章主题}/
├── article.md | source.md | transcript.md
└── notes.md
```

- 有明确作者：放 `investment/{作者}/{文章主题}/`
- 来自机构但无个人作者：放 `investment/{机构}/{文章主题}/`
- 多作者材料：放主作者目录，并在其他作者索引中交叉引用
- 确实无法识别作者/机构：暂放 `investment/unknown/{文章主题}/`，后续补充来源信息
- 主题综合、投资计划、资产配置结论是自己的二次研究，可放在 `investment/` 根目录或专题目录

`sources/sources.jsonl` 负责记录来源与输出路径；`paper-reading` skill 负责处理长文本；最终笔记归属到作者/机构目录。
