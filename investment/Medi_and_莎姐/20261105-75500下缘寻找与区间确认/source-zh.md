# 莎姐：75,500 下缘寻找、区间确认与数据分层（中文整理）

本轮新增目标人物发言均为中文，因此无需逐句翻译。英文术语按上下文整理如下：

- `range low`：横盘区间下缘。本轮强调它不是事先完全确定的单点，而是市场经过反复测试后才能确认的区域。
- `range high`：横盘区间上缘。84,600—86k 的上缘经过多次波动后才被市场识别，并用于计算对应的 75,500 附近下缘。
- `prolong sideways`：持续延长的横盘。本轮补充的信息是，延长横盘会反复寻找下缘，因此下缘的定位可能不会像单一交易点那样精确。
- `higher low`：更高的低点。莎姐把它列为继续等待的一种可能，但并未确认 75.7k 就是当前低点。
- `data` / `Glassnode` / `orderflow`：数据、链上数据工具与订单流。她认为数据应服务于结构认知和仓位规模；大仓位更需要用它们评估滑点、市场深度和整体流动性，普通仓位则不必把高级数据当作交易前提。
- `trade`：交易方案。她指出，设计一笔交易还包括其他判断，但所有判断最终都要从结构认识开始。
