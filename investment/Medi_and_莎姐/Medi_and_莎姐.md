## 关键观点速查

| 主题 | 观点 | 出处 |
|------|------|------|
| Swing 定义 | 创造了局部新高或新低的一段移动；起点 = 该移动的起始点 | 私信 2026-04-16 |
| 结构优先于周期 | 不先固定 K 线周期；先划定完整结构，再在结构内部寻找明显止损。本例结构为 2026-06-03 至今 | 微信群 2026-08-18 |
| 新结构判定 | ①Candle close 突破 range ②产生突破的 Swing 起点 = 新结构起点 | 私信 2026-01-11 |
| Sweep vs 新结构 | Sweep 仍属原始结构；真正的 close 突破 + 对应 Swing 才开启新结构 | 私信 2026-01-11 |
| 流动性计算前提 | 先识别 structure → 寻找 trap/resting liquidity compression → 基于仓位计算 target | 群聊 2026-03-16 |
| 目标位与反向信号 | 到达流动性目标只触发止盈；必须等到与底部同等级的精准反应，才考虑反向仓位 | 微信群 2026-08-18 |
| 区间仓位管理 | 关键位分批止盈、保留尾仓，并在上方精准反应出现后用空头对冲剩余多头 | 微信群 2026-08-18 |
| 目标完成后重置叙事 | 目标达成即结束原交易；随后必须根据新结构和剩余流动性重新判断，不能沿用旧入场理由 | 微信群 2026-08-19—21 |
| Sweep 的入场确认 | 刺穿关键位本身不构成入场；价格重新回到关键位下方并发生拒绝，才确认局部做空 | 微信群 2026-08-20 |
| 流动性使用后的方向变化 | 上方流动性被使用后，旧支撑位的深度回撤不再天然看多；需重新评估结构健康度 | 微信群 2026-08-21 |

| 结构与波浪分工 | 结构用于精准进场；波浪用于描述ABC与五浪展开，除非极高水平否则难以精准入场 | 莎姐，微信群 2026-08-22 |
| 周末信号处理 | 周六确认通常不可靠；若量能异常可小仓试单，但必须降低信任度并设置止损 | 莎姐，微信群 2026-08-22 |
| 出货位与反向入场分离 | 到达目标/出货区只结束原仓位；反向开仓必须等待独立结构，不能直接翻仓 | 莎姐，微信群 2026-08-24 |
