## 核心论点

全球债券收益率同步飙升是**结构性**问题而非短期冲击——战争无法结束 + 油价高企 + 各国财政扩张（军费）三重驱动，形成通胀预期→加息→债息上升的自我强化循环。

---

## 关键论据与数据

### 1. 通胀传导的现实感知

| 指标 | 涨幅 | 备注 |
|------|------|------|
| 美国汽油价格 | +100% | 去年至今 |
| 食用油 | +60-70% | |
| 面粉、咖啡 | +50%以上 | |
| WTI spot | 回到100美元以上 | |

- 美国30年国债收益率达5%（"警戒水平"）
- 日本债息创有统计以来最高

### 2. 战争-通胀-财政的恶性循环

- 中东战争无法结束：美国要求伊朗放弃核计划→"基本上没有谈得成的可能性"→军事行动再次进行
- 各国财政预算增加：日本首相正准备增加预算应对大宗商品价格冲击
- 英国：通胀预期高企 + 军费开支 → 债息被推高

### 3. 日元困局：方程式中唯一要"投降"的变量

- 日本需要宽松货币政策支持经济 → 但通胀环境下宽松 → 日元必须贬值
- 当前约160，洪灏认为到180"是大概率事件"
- 日本央行"放话式干预"——"做得住一时做不住一世"
- 债息上升是补偿投资者持有日债所经受的购买力损失

### 4. 全球债券同步抛售：驳"轮动说"

**关键论证**：如果是日本卖美债买日债（轮动），应看到美债收益率升+日债收益率降。但现实是日债收益率上升速度比美债更快 → 不是轮动，而是全球所有债券同时被驱动。

- 日本3月减持美债：官员否认是为了卖美债买日元（"卖美债推高美债利率对日元也没好处"）
- 日本主权基金3月净流入7亿美元 → 部分机构确实在带钱回国
- 但洪灏认为"不需要卖美债来筹钱，因为可以印钞"——印钞后果是汇率贬值+通胀上升

### 5. 中国减持美债的"隐身术"

- 中国减持美债的趋势会继续维持
- 但"只看官方数据"是片面的：大型主权机构操作时不暴露底牌，会用**其他小帐户、命名帐户**做操作
- 类比做市场交易：如果对手知道你的持仓/意图，会利用信息优势压制你的价格

### 6. 加息预期

- 期货/掉期市场已定价：明年3月底前可能加息
- 洪灏认为在货币没有开放（资本管制）的前提下，通胀上升+加息"未必是短期问题，可能变成结构性问题"
