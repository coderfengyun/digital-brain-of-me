## 核心论证链

### 1. 周期定位：35年长周期顶部

- 量化周期理论：长周期35年 = 10个3.5年小周期；两个35年 ≈ 一个康波（70年）
- 2009年次贷危机为上一个周期底部 → 2026年距底部17年 = 35年长周期的顶部
- 丙午火年（赤马红羊）与周期顶部吻合
- **前瞻验证**：去年11月预测"黄金与股票同时飙升预示山雨欲来"（上一次同时飙升：1929年）

### 2. 美联储扩表 → 泡沫助力

- **验证**：美联储确实按预测在买入短债扩表（图2）
- **泡沫经典定义**：民众对股市信心空前高涨 vs 对经济基本面预期跌至历史谷底 → 预期差达历史最高
- 去年11月预测路径："买短扩表 → 初始膝跳反应上涨 → 消化后开启下跌模式"

### 3. 伊朗战争对油价的影响——暂时稳定但潜藏风险

- 油价冲120美元后快速回落（4月量化模型反"常识"预测暴跌）
- 稳定因素：中国释放十几亿桶战略储备（每天1000万桶）、沙特红海绕道、俄油禁运暂解、美国增产
- **风险**：战略储备以史无前例速度消耗 → 若战争几个月内不解决 → 油价再飙 + 期货曲线正挂
- 停战后油价仍居高难下：航运恢复需时间 + 部分产能被破坏 + 化肥生产受损

### 4. 沃什的政策困境

- 矛盾目标：物价稳定（需加息） vs 市场稳定（需宽松，为中期选举护航）
- 市场定价：年底前至少加息一次
- 2000年类比：美股互联网泡沫在美联储连续第五次加息时崩塌

### 5. AI CAPEX 驱动经济韧性 + 通胀

- 万亿美元级AI资本支出延伸了美国经济周期（图3）
- 溢出效应 → 上游大宗商品需求激增（图5："AI超级泡沫就是金属超级周期"）
- 流动性条件变化领先通胀预期 → 未来数月通胀大概率上升（无论油价如何，图6）

### 6. 黄金白银泡沫四大启示 → 映射AI半导体

| 启示 | 金银泡沫表现 | AI半导体映射 |
|------|-------------|-------------|
| ①抛物线上涨→抛物线下跌 | 黄金1000→5600美元，白银10→121美元 | 半导体一个月涨50%+（6倍方差事件）；图9显示抛物线走势 |
| ②杠杆断裂 | CME连续上调保证金 → 暴力拆杠杆 | 美联储加息=资金成本上升，市场尚未计入；negative gamma加速 |
| ③估值极端化 | 金银无估值（纯投机），但收益率极端化 | 半导体个位数PE实为周期顶部信号（周期股顶部估值最低） |
| ④泡沫消化需时间 | 2015A股一年、2021半导体一年+、2000纳指20年+ | 预示AI泡沫崩裂后清算期不会短 |

### 7. AI半导体：交易结构放大器

- 401K增加股票配置 → 被动资金流入
- 期权交易量>现货 → 券商对冲产生"负伽马效应"（越涨越买）
- 杠杆ETF增多
- 特朗普TACO + 美联储扩表兜底
- **结论**：基本面未变但交易结构制造了90度角暴涨

### 8. 长协的虚幻确定性

- 市场共识：长协锁定需求+价格→半导体不再是周期股
- **反驳**：
  - 多数长协未公开锁价条款，很可能只锁量不锁价
  - 2021年车用芯片长协→2023年全面预警（库存消化替代新采购）
  - 2017年存储短缺退潮后价格两三个季度跌40%+
  - 技术演进降低需求（NVIDIA减半存储用量、DeepSeek Moment）
- 半导体价格指数领先纳指6-12个月，但其上升势头远慢于纳指（图11b）

### 9. SpaceX IPO — 对地面数据中心的颠覆叙事

- 马斯克计划：太空数据中心（太阳能供电+真空冷却+近地卫星回传）
- 算力 = 地表所有数据中心1000倍，成本远低
- 每公斤运载成本降至<30美元（低于跨洋运费）
- **投资含义**：对当前万亿级地面AI基础设施商业模式的根本颠覆

## 下半篇核心论证链（2/2，2026-06-12）

### 10. 亚洲汇率格局裂变

- 韩元贬值至2009年金融危机以来最低
- 日本央行4-5月花近800亿美元干预汇率（史上最大）→ 减持美债筹款 → 推高美债收益率
- 日元仍在160附近，贬值预期难消散
- 人民币突破6.8关口，升至三年新高（2024.11预测升值30%验证中）
- **关键洞察**：韩元、日元贬值反而让日韩对外资本账户受益（持有大量海外资产）

### 11. 人民币套利交易（核心新论点）

**套利交易三要素**：
1. 稳定的汇率贬值预期 ✓
2. 稳定的息差 ✓
3. 单边强势的资产价格走势 ✓

**中国宏观之谜**：每年1万亿+美元贸易盈余 → 外储十年不变（3万亿出头）→ 人民币严重低估 → 推论：大量中国出口美元滞留境外参与海外投机

**传导逻辑**：人民币升值 → 逆转人民币套利交易 → 海外风险资产承压 → 但中国资产（尤其防御性"老登股"）将在全球重定价中彰显韧性

**领先指标**：人民币汇率走势领先风险资产（半导体）走势（图16）

### 12. 2000年泡沫精确拟合

- 量化分析发现2026年美股走势与2000年泡沫登顶相关性最高（标普、纳指、道指均吻合）
- **时间推演**：纳指距大级别顶部约2-3个月（调整窗口已开启）
- **2000年见顶顺序**：纳指(2000.3) → 标普(2000.9) → 道指(2001Q1) → 经济衰退(2001Q1)
- **当前估值**：标普长期PE历史最高 > 2000年互联网泡沫 > 2021年财政货币化时期；CAPE亦然

### 13. 流动性拐点——泡沫崩裂的触发器

- 2025.11预测：今年Q2全球流动性进入拐点 → 已验证（图22）
- 流动性条件变化**领先资产价格3个月** → 未来数月大级别调整/周期性见顶
- **触发机制**：
  - 沃什加息（通胀回4%+，远超美联储目标）
  - 长端美债收益率跳升（由全球市场定价，沃什无法控制）
  - 日本央行可能加息
  - 中国央行回收万亿级流动性
- **2000年类比**：第五次加息才刺破泡沫；前几次加息市场甚至上涨

### 14. AI CAPEX的信仰vs信心

- 2026 vs 2000的最大不同：科技七雄有实际现金流和盈利（2000年多是概念股）
- NVIDIA vs Cisco（路由器）类比：相似点（产业链核心+投资下游）但NVIDIA芯片需求和迭代是事实
- **核心风险**：AI CAPEX回报尚未验证 = "信仰"而非"信心"
  - 流动性宽裕时：信仰无需数据支撑
  - 流动性收紧时：信仰会被一两个关键数据击碎
- **领先指标**：AI代币价格冲顶回落 → 半导体板块股价领先指标（图25）

### 15. 中国经济周期与市场展望

**经济周期**：
- 2026 GDP目标4.5%-5%（1991年以来最保守）
- Q1 GDP 5%后Q2放缓（量化周期指标二月预测验证）
- 经济周期下行阶段**尚未结束**

**央行扩表**：
- 势能达历史高位 → 但从历史看此规模后往往边际放缓
- 2022年后央行扩表对房地产影响式微 → 主要影响股市
- 国债十年收益率与央行扩表/股市走势分道扬镳 → 长端收益率下行动力>上行

**成长vs价值**：
- 成长股相对价值股表现达历史极端（图28）
- 若央行扩表势能放缓 + 风险偏好转弱 → 成长超额收益收敛 → 老登股回归

**恒指**：
- 领先指标已触底反弹，但下行压力尚未释放完毕（图29）
- 三季度后恒指/恒科很可能出现机会

**市场情绪**：
- 快速变冷至历史次低（上次2024年初 → 随后两年表现不俗）
- 情绪是反向指标

**长期看**：中国GDP货币化率仍很低 → 市值和指数将创历史新高
