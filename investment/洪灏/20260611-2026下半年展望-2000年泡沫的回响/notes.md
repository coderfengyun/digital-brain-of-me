## 核心论证链

### 1. 周期定位：35年长周期顶部

- 量化周期理论：长周期35年 = 10个3.5年小周期；两个35年 ≈ 一个康波（70年）
- 2009年次贷危机为上一个周期底部 → 2026年距底部17年 = 35年长周期的顶部
- 丙午火年（赤马红羊）与周期顶部吻合
- **前瞻验证**：去年11月预测"黄金与股票同时飙升预示山雨欲来"（上一次同时飙升：1929年）

### 2. 美联储扩表 → 泡沫助力

- **验证**：美联储确实按预测在买入短债扩表（图2）
- **泡沫经典定义**：民众对股市信心空前高涨 vs 对经济基本面预期跌至历史谷底 → 预期差达历史最高
- 去年11月预测路径："买短扩表 → 初始膝跳反应上涨 → 消化后开启下跌模式"

### 3. 伊朗战争对油价的影响——暂时稳定但潜藏风险

- 油价冲120美元后快速回落（4月量化模型反"常识"预测暴跌）
- 稳定因素：中国释放十几亿桶战略储备（每天1000万桶）、沙特红海绕道、俄油禁运暂解、美国增产
- **风险**：战略储备以史无前例速度消耗 → 若战争几个月内不解决 → 油价再飙 + 期货曲线正挂
- 停战后油价仍居高难下：航运恢复需时间 + 部分产能被破坏 + 化肥生产受损

### 4. 沃什的政策困境

- 矛盾目标：物价稳定（需加息） vs 市场稳定（需宽松，为中期选举护航）
- 市场定价：年底前至少加息一次
- 2000年类比：美股互联网泡沫在美联储连续第五次加息时崩塌

### 5. AI CAPEX 驱动经济韧性 + 通胀

- 万亿美元级AI资本支出延伸了美国经济周期（图3）
- 溢出效应 → 上游大宗商品需求激增（图5："AI超级泡沫就是金属超级周期"）
- 流动性条件变化领先通胀预期 → 未来数月通胀大概率上升（无论油价如何，图6）

### 6. 黄金白银泡沫四大启示 → 映射AI半导体

| 启示 | 金银泡沫表现 | AI半导体映射 |
|------|-------------|-------------|
| ①抛物线上涨→抛物线下跌 | 黄金1000→5600美元，白银10→121美元 | 半导体一个月涨50%+（6倍方差事件）；图9显示抛物线走势 |
| ②杠杆断裂 | CME连续上调保证金 → 暴力拆杠杆 | 美联储加息=资金成本上升，市场尚未计入；negative gamma加速 |
| ③估值极端化 | 金银无估值（纯投机），但收益率极端化 | 半导体个位数PE实为周期顶部信号（周期股顶部估值最低） |
| ④泡沫消化需时间 | 2015A股一年、2021半导体一年+、2000纳指20年+ | 预示AI泡沫崩裂后清算期不会短 |

### 7. AI半导体：交易结构放大器

- 401K增加股票配置 → 被动资金流入
- 期权交易量>现货 → 券商对冲产生"负伽马效应"（越涨越买）
- 杠杆ETF增多
- 特朗普TACO + 美联储扩表兜底
- **结论**：基本面未变但交易结构制造了90度角暴涨

### 8. 长协的虚幻确定性

- 市场共识：长协锁定需求+价格→半导体不再是周期股
- **反驳**：
  - 多数长协未公开锁价条款，很可能只锁量不锁价
  - 2021年车用芯片长协→2023年全面预警（库存消化替代新采购）
  - 2017年存储短缺退潮后价格两三个季度跌40%+
  - 技术演进降低需求（NVIDIA减半存储用量、DeepSeek Moment）
- 半导体价格指数领先纳指6-12个月，但其上升势头远慢于纳指（图11b）

### 9. SpaceX IPO — 对地面数据中心的颠覆叙事

- 马斯克计划：太空数据中心（太阳能供电+真空冷却+近地卫星回传）
- 算力 = 地表所有数据中心1000倍，成本远低
- 每公斤运载成本降至<30美元（低于跨洋运费）
- **投资含义**：对当前万亿级地面AI基础设施商业模式的根本颠覆
