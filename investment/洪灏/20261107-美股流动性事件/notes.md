# 从流动性冲击到基本面恶化：风险传导的关键分叉

## 一句话摘要

洪灏把当前美股急跌首先定义为流动性事件，但用硅谷银行和瑞信提醒：若被迫去杠杆反过来损伤融资、信用与资产负债表，技术性抛售会内生为基本面恶化。

## 论证结构

```text
极端波动与拥挤仓位去杠杆
→ 保证金、赎回与流动性需求触发抛售
→ 若市场深度恢复：停留在流动性事件
→ 若融资收紧、抵押品贬值、信用利差扩大
→ 资产负债表受损并反馈到实体与盈利
→ 流动性事件升级为基本面事件
```

## 证据与局限

- 亚洲高硬件权重市场约跌 6%，但中资宽基约跌 1%，支持“冲击与基本面并非等比例变化”的初步判断。
- 美股强劲非农、半导体反弹与 VIX 回落支持短期流动性修复；但周度大跌、长端利率高企和信用风险仍需观察。
- SVB/瑞信是传导机制案例，不代表本轮必然重演；关键在银行融资、信用利差和抵押品链条是否继续恶化。

## 验证仪表盘

跟踪市场深度与融资利差、信用违约掉期、银行融资、被动基金申赎、保证金余额，以及盈利预期是否随价格下跌而下修。
